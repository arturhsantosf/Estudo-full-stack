Estudo Full Stack

Projeto full-stack de estudo, com back-end em Node.js e banco de dados MongoDB.

Tecnologias
Item	Ferramenta	Função
Ambiente	Node.js 20.19 ou superior	Executa o back-end
Banco de dados	MongoDB	Armazena os dados
Modelagem	Mongoose 9	Conecta o Node.js ao MongoDB e define os modelos de dados
Integração	CORS 2.8	Permite que o front-end, em outra origem, acesse a API
Pré-requisitos
Node.js 20.19 ou superior (o Mongoose 9 exige essa versão)
npm, que já vem com o Node.js
Uma instância do MongoDB, local ou no MongoDB Atlas
Instalação
bash
# Clone o repositório
git clone https://github.com/arturhsantosf/Estudo-full-stack.git

# Entre na pasta do projeto
cd Estudo-full-stack

# Instale as dependências
npm install
O que aprendi
Conectar uma aplicação Node.js a um banco MongoDB usando Mongoose
Liberar o acesso do front-end à API com CORS
Gerenciar dependências com npm (package.json e package-lock.json)
Versionar o projeto com Git e GitHub, ignorando arquivos como node_modules
